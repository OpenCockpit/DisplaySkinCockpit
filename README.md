# DisplaySkinCockpit

![Screenshot](prev.png)

## Features
DisplaySkinCockpit is a skin for Enigma2 receivers with a 396x240 pixel LCD/VFD front panel display. It provides display screens without bells and whistles optimized for a larger viewing distance (like 5 m) - see the [screen gallery](docs/gallery.md) for previews of various screens.

## Limitations
- Tested on OpenViX and OpenATV with DM900.
